# Native spatial controls

The serial UI worker accepts one complete bounded SpatialSettings DTO and current preparation identity/generation. Parsing is strict; the portable spatial validator checks all geometry, IDs/names and finite ranges. An active voice gesture rejects the edit before quiet re-preparation. A successful edit copies the current verified timeline and current voice drafts, replaces only AudioSettings.spatial, stops Listening and returns a new preparation. Composition, provenance and exact rational time remain intact.

A persistent provider owns one raw-text draft and one in-flight apply above page switches. Sound Studio edits up to eight ordered user-authored bounds. First match wins, including dateline bounds; no ecological habitat or animal position is inferred. Existing 2D cartography previews bounds. Station positions remain receiver observations; missing/outside positions are explicitly unassigned.

Explicit Apply drains acknowledged voice gestures and applies only that editor's draft. Save drains composition then spatial sequentially; each fetches the current native preparation before setting, so the second cannot reuse the first's stale identity. Preparation-only refresh preserves the other editor's unsaved draft; recall epoch/source/settings replacement resets exact saved controls. Invalid temporary number text stays editable and blocks native apply/capture.

Verification uses pure DTO/text/boundary/barrier tests and disposable silent native browser capture/recall/export, held acknowledgements, malformed/stale requests, ordered regions, stereo WAV differences, quiet recall and unchanged immutable exports. Physical output, actual DAW tests and owner listening approval remain separate.
