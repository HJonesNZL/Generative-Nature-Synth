# Native Sound Studio host integration

**Historical first-voice checkpoint.** The expanded current implementation is specified in [Voice character contract](VOICE_CHARACTER_CONTRACT.md), [Voice store v2](NATIVE_VOICE_STORE_CONTRACT.md) and [Soundscapes milestone](SOUNDSCAPES_AND_SPECIES_CANDIDATES.md). Four-control and struck-only limits below describe the earlier revision.

The optional JUCE audio host now borrows a worker-owned `VoiceStore` alongside its playback runtime. The data-only host remains read-only and does not advertise voice editing. This milestone supplies one implemented struck tone, four per-species parameters and explicit saved definitions. It is not full piece/session sound recall or a final synthesis palette.

## Data and control flow

The launcher sets `ATLAS_VOICE_LIBRARY` to `.state/voices.sqlite3` in the canonical workspace. Direct audio-host invocation uses that environment override, otherwise `voices.sqlite3` beside the selected animal library. The preset file must be separate from the wildlife library: the host rejects canonical-path or existing-hardlink equality; the store independently refuses nonempty foreign schemas. A preset initialization error is reported on stderr and the host exits; it does not erase or silently replace presets. Tests override the path with disposable storage, including inherited environment overrides. No collector is started or altered.

Native capabilities add `getVoiceLibrary`, `getVoice`, `setVoiceParameter`, `saveVoice` and `revertVoice`. The shared DTO remains `ui/contracts.ts`. IDs and saved/change revisions are strings; normalized values are finite numbers in [0,1]. Parameter metadata comes from the native store's single specification table. The native type list contains only `struck`, with `proposal:false`. The fallback definition has ID `default` and group target `native`; it is used for events without a mapped species. Every known species has an independent definition; there is no inherited default propagation or invented individual identity.

The voice list discovers species from the bounded current library catalogue and retains persisted species absent from that sample. Preparing a verified saved piece registers all of its actual species and compiles default-plus-species numeric slots. Definitions are bounded to 513 including fallback. A capacity failure is explicit; ordinary Atlas catalogue reads remain independent of this audio capacity. Display names are source metadata, not durable preset fields.

Slot mappings are staged with a new audio plan and published only after successful preparation. If another piece fails validation or audio preparation, the previous disabled plan retains its original slot associations. This prevents an edit to the rejected piece's species from altering a retained species. Browsing material does not replace playback. Preparing a new piece uses current drafts, so unsaved edits remain in memory until the host exits.

Each edit validates a prospective draft, compiles numeric settings on the worker, waits for runtime acknowledgement when output is active, then commits the draft. Editing does not change preparation/generation or restart the device. A timed-out update may have reached the callback: the host quiesces output and restores the previous authoritative settings before reporting failure. If the failed phase was `end`, it closes that gesture at its last acknowledged value so recovery remains usable. The UI must not automatically retry a mutation.

Save requires no active gestures and a matching saved revision, then commits the sidecar before acknowledging success. Revert first reloads authoritative durable state and then updates future notes. If its audio update fails, output is stopped and the reverted bank is applied while quiescent; the response explicitly reports that the voice reverted but audio stopped. The UI refetches authoritative state on this failure. Corruption, invalid input, active gestures, capacity and competing writers remain observable errors.

## Scope and verification

Only future note onsets capture edits; ringing notes retain their pitch, gain and envelope. Editable plans reserve up to 3.12 seconds after the final admitted onset. Transport can therefore include silent time after a short note. Global master remains fixed at −18 dB. Eight primary and eight retiring states remain bounded. Synthesis and storage specifications are in `NATIVE_VOICE_DSP_CONTRACT.md` and `NATIVE_VOICE_STORE_CONTRACT.md`.

The existing CLI WAV renderer still uses its explicit CLI audio settings; it does not consume this preset sidecar. Exporting a complete authored soundscape, individual overrides, extra synthesis types, mapping/modulation editors, regional effects, native audition selection and full project recall remain later milestones. No unsupported controls are enabled by the native capability list.

Regression coverage uses disposable SQLite files and a clocked synthetic output driver. It checks protocol validation, canonical parameter acknowledgement, explicit save/reopen, no autosave, competing writers, unchanged wildlife content, no device restart, wrong-species protection after failed preparation, and failed end-gesture recovery. The failed-preparation test checks rendered PCM, not just protocol success. The real JUCE executable is also exercised in prepare-only mode for editing/save/EOF lifecycle without opening an output device. Retained results and current qualification limits are in `evidence/native-voices/`.
