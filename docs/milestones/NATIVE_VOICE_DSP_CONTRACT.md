# Native first-voice profiles and editing contract

7 November 2026. This extends the experimental three-partial struck voice from M2 and the native playback contract. It is a first-voice engineering milestone within the complete synthesizer plan; no final timbre, hardware qualification or owner listening approval is implied. ADSR sustain/release controls, tone, pan and additional synthesis families remain unsupported.

## Parameters and sound

`VoiceSettings` has integer `tuningSemitones` in -12..12 (default 0), `attackSeconds` in .002...100 (default .008), exponential T60 `decaySeconds` in .100..3.000 (default .650), and `gainDb` in -60..0 (default 0). All floating values must be finite. The existing global settings remain separate; native playback defaults to -18 dB master. Profile tuning shifts the existing deterministic species-hash mapping rather than replacing its intervals. The effective root, global root plus tuning, must remain MIDI 48..72. Live root 60 therefore admits all tuning values. Individual species hash offsets remain [0,2,4,7,9,12,14,16].

For sample rate F, prepare A=ceil(attackSeconds*F), D=ceil(decaySeconds*F), R=ceil(.020*F), p=2^(tuningSemitones/12), q=exp(-ln(1000)/D), and g=10^(gainDb/20) on the serial control worker. Each onset copies these coefficients into its own voice. Its phase step is the immutable action phase step times p. At age n, before updating phase:

- a[n]=(1-cos(pi*n/A))/2 for n<A, otherwise 1;
- d[n]=exp(-ln(1000)*max(0,n-A)/D), evaluated by multiplying the stored decay by q after the sample at n>=A;
- r[n]=1 before A+D, then (1+cos(pi*(n-A-D)/R))/2, with exact silence at A+D+R;
- v[n]=.05*g*a[n]*d[n]*r[n]*(sin(theta)+.25*sin(2*theta)+.08*sin(3*theta))/1.33.

The inherited phase update, 5 ms retirement fade, transport fades, eight primary/eight retiring states, deterministic stealing and finite-state fault recovery are unchanged. Pitch, envelope and gain edits use **new-notes semantics**: already ringing primary and retiring notes retain the complete original coefficient set. No ramp is applied to a newly edited setting because it does not retarget a running oscillator or envelope. Repeated edits replace the bank slot; each next note captures the last acknowledged value. Stop/panic/seek clear audio history as before and retain the current bank settings. Rate changes still require a newly prepared plan. There is no added audio buffering or intentional audio latency.

Profile gain only attenuates. Each voice remains bounded by .05 and all 16 states by .8 before global attenuation. At the lowest supported rate, even the largest allowed root/offset/transposition keeps the third sinusoidal carrier below Nyquist; the inherited envelope sidebands are not claimed to be mathematically bandlimited. Finite note lifetimes prevent unbounded or denormal tails.

## Bank, compilation and capacity

`AudioPlan(timeline, globalSettings, profiles, editableVoices)` compiles every species ID lookup off-thread. An empty profile span preserves the exact original mapping, PCM and plan-duration behavior. A nonempty span contains an empty-species-ID default at slot 0 followed by up to 512 unique nonempty species IDs. Its stable span order defines `VoiceSlot` (`uint16_t`); missing/unmapped species use slot 0. Duplicate IDs, a missing/duplicate default, invalid parameters or more than 513 total entries fail preparation. The plan copies profile strings and the initial fixed numeric bank. `voiceSlot(speciesId)` and `voiceProfiles()` are worker APIs; the callback never calls the string lookup.

Every `MusicalAction` contains only numeric data, including its slot. The renderer preallocates a 513-entry numeric bank and the 16 bounded voice states. A note copies one bank entry at onset; retirement copies its captured note state. No species matching, sorting or dynamic voice growth occurs in audio processing. Plan ownership and callback quiescence before destruction remain governed by the native playback contract.

An editable plan reserves the maximum legal note lifetime, ceil(.100*F)+ceil(3*F)+ceil(.020*F), after **each admitted onset**, even when its initial decay is shorter. This conservative immutable end bound allows a later longer decay to finish without plan replacement. It can append silent time, and intentionally changes editable-plan duration relative to legacy preparation. Fixed profile plans reserve the actual initial per-slot lifetimes. Empty windows remain preserved. Transport may therefore run silently to the reserved end after short notes.

## Update ownership and acknowledgement

`PlaybackRuntime::updateVoice(slot, settings)` runs on the existing single serial control worker. It checks preparation, editability, slot, finite values and ranges; prepares all coefficient math off-thread; then publishes a fixed numeric `PlaybackCommand` through the existing one-command SPSC mailbox. The command carries preparation and transport generation checks and receives the existing callback acknowledgement. An accepted update does not change the preparation ID or transport generation, stop/restart the device, rebuild the plan, seek or change the play state. The worker's settings store owns authored settings/revisions; the plan's profiles describe initial preparation rather than a concurrent mutable UI model.

When output is disabled/quiescent the same numeric update applies directly. When enabled the callback consumes at most one mailbox command at block start, performs bounded scalar range checks and copies one bank entry. Its work does not depend on species count. No strings, allocation/deallocation, locks, waiting, coefficient exponentials, storage, UI or last-owner destruction enter this path. The worker owns the payload until release-publishing `request`; the callback owns it until release-publishing `acknowledged`; the worker waits with acquire before writing another payload. Timeout/device-failure handling establishes callback quiescence before reclaiming that ownership, as for transport commands. Invalid worker settings return `invalid_voice_settings`; unavailable preparation and mailbox/device errors retain their existing typed errors. A coefficient payload is also defensively constrained to valid frame/lifetime, attenuation, finite decay and pitch bounds in the renderer.

## Evidence and limits

`native/tests/voice_audio_tests.cpp` checks an independent closed-form oscillator/envelope/gain equation at 22.05, 48 and 192 kHz with normal and extreme controls; exact default profile/legacy PCM; partition equality; preserved deterministic species pitches; species isolation and onset-captured state after a live edit; audible late samples from a longer edited decay; the conservative end bound; all 513 slots; invalid/malformed banks and parameters; combined root limits; quiescent and acknowledged runtime edits; unchanged device/preparation/generation/play state; and C++ allocation/deallocation guards around actual callback/update processing. The actual VoiceStore normalized gesture/save/reopen path additionally retains exact physical default identities and exact legacy PCM at 22.05, 44.1, 48, 96 and 192 kHz; attack/T60 frame boundaries are checked at every supported integer rate from 22,050 through 192,000 Hz. A deterministic 72,000-case normalized endpoint, adjacent-representable-value and random-value probe spans six rates and checks physical ranges, exact endpoints, worker compilation and callback acceptance. These are numerical/contract checks, not a listening or performance benchmark. The inherited audio and playback suites exercise density/stealing, transport, mailbox timeout, leases, lifecycle and default output parity.

This uses the existing M2 closed-form additive/envelope derivation and standard dB/semitone ratios; no public DSP implementation or new synthesis dependency is copied. Passing hardware-free tests establishes numerical, ownership and bounded-capacity evidence for this path. Real output, sustained callback timing, physical latency, DAW use and owner listening for edited profiles are not run by these tests.
