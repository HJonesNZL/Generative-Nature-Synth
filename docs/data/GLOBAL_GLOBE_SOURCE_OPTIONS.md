# Zero-cost global globe source options

Research checked 7 November 2026 against official documentation; no records downloaded, credentials used, collector changed or owner database accessed. This is an integration decision memo, not reuse clearance. Public access does not establish permission to redistribute records or derived products. None of these sources promises all-species, worldwide real-time tracking.

## Owner update: individual tracking takes priority

After this research, the owner explicitly retained live listening/detection streams and requested separate individual-animal location tracking for other streams. The original broad-occurrence ranking below is superseded as an implementation priority: start with a vetted historical Movebank tracking package and source-specific tracking reliability, while keeping existing acoustic feeds. GBIF, iNaturalist and OBIS occurrence research remains optional/deferred; it must not replace individual tracking or invent animal identity. The bounded offline pilots under `data-pilots/` are integration preparation, not enabled collectors or approved datasets.

## Original research ranking (superseded by owner priority)

1. **GBIF bounded occurrence pilot:** strongest broad geographic/taxonomic overview with explicit licence metadata and anonymous small searches. Start with one animal taxon, one fixed historical interval and a strict record budget. Label points “reported species occurrences”; do not connect them as individual tracks. Exclude media and unresolved/NC licences from any distributable pilot pending intended-use review.
2. **One Movebank Data Repository study:** best next step for genuine historical individual movement. Select a small published package only after checking its DOI, licence, permitted reuse, sensitivity, individual/deployment identifiers and timestamps. Keep it visibly historical/imported; do not imply an ongoing live feed.
3. **iNaturalist bounded recent-sightings layer:** useful when recency of community submissions matters, but observation time, submission time and subsequent identification edits differ. Its privacy/correction handling and request budget need explicit implementation.
4. **OBIS marine occurrence layer:** useful marine depth, including sampling/event context. Introduce after cross-source provenance/deduplication and licence handling exist; it is not a general terrestrial tracking source.

This ranking is engineering judgement for this globe/zero-cost scope. Existing operational sources remain in place. Full-library native overview/pagination in [GLOBE_PREVIEW.md](../milestones/GLOBE_PREVIEW.md) is an independent prerequisite: more upstream data cannot fix a 200-revision initial UI buffer.

## Comparison

| Source | What positions mean; time/history | Access and practical limits | Privacy and reuse gates |
|---|---|---|---|
| **GBIF** | Biodiversity occurrence records, not automatically individual trajectories. Filter historical occurrence dates; retain observation date precision separately from publisher/indexing timestamps. No freshness SLA established here. | Public search needs no API key; pages max **300**, search offset+limit max **100,000**. Larger sets use asynchronous download with registered username/password. Rate is load-dependent; **429** means reduce requests. GBIF recommends downloads for search jobs taking more than about 15 minutes. [API](https://techdocs.gbif.org/en/openapi/v1/occurrence), [rate guidance](https://techdocs.gbif.org/en/openapi/). | Dataset/record licence can be CC0, CC BY or CC BY-NC; retain dataset attribution/citation, and check media separately. Publishers generalize/withhold sensitive data; preserve uncertainty, `dataGeneralizations` and `informationWithheld`, never recover hidden positions. [Licensing](https://www.gbif.org/publishing-data), [record/dataset consistency](https://ipt.gbif.org/manual/en/ipt/latest/applying-license), [sensitive data guidance](https://docs.gbif.org/sensitive-species-data-generalization/en/). |
| **iNaturalist** | Observer-submitted species sightings; an observation or observer ID is not an animal ID. API distinguishes observed-date filters `d1/d2`, created-date filters and update sorting; recent upload does not establish recent animal presence. Historical search available. | Public observation reads support anonymous use; authenticated operations use account/JWT/OAuth. Generally max **200/page**; deep paging needs documented ID-based pagination rather than an all-world scrape. Developer ceiling **100/min**, requested **≤60/min**; recommended practice about **1/s** and **10,000/day**. API is not a bulk-download channel; exports/weekly GBIF archive are alternatives. [API schema](https://api.inaturalist.org/v1/swagger.json), [practices](https://www.inaturalist.org/pages/api%2Brecommended%2Bpractices), [developers](https://www.inaturalist.org/pages/developers). | Observation and photo licences can differ; no blanket media permission. Obscured points are randomized within a **0.2° cell** with increased uncertainty; private coordinates are hidden. Treat obscured time/location as coarse even if API details could enable inference; do not cross-link to reconstruct locations. [Licences](https://www.inaturalist.org/blog/88417-how-and-why-to-update-observation-licences), [current privacy help](https://help.inaturalist.org/en/support/solutions/articles/151000169938). |
| **OBIS** | Marine occurrence and sampling-event data; source datasets may include telemetry but ordinary occurrences do not prove individual movement. Preserve `eventDate`/date ranges; publication/indexing is distinct. Historical subsets/downloads exist; no real-time SLA established. | Public API/exports; documented public reads do not require a paid key. Mapper, dataset downloads and full exports are distinct routes. Point/grid GeoJSON endpoints document **100,000-feature** limits; do not confuse the interactive explorer's default ten examples with a global record limit. Fixed requests/second and exact occurrence page budget **not verified**; confirm before polling. [Access](https://manual.obis.org/access), [API](https://api.obis.org/), [date interpretation](https://manual.obis.org/FAQ.html). | Accepted licences include CC0/BY/BY-NC; dataset citation/provider restrictions still apply. Preserve uncertainty/withheld fields and inspect provider sensitivity policy; a platform-wide coordinate-obscuring guarantee was **not established**. OBIS policy also requires respect for Indigenous authority/CARE. [Policy](https://manual.obis.org/policy.html), [Darwin Core](https://manual.obis.org/darwin_core.html). |
| **Movebank / Repository** | Actual tagged-individual sensor events with study/animal/deployment context. API supports UTC time windows and bounded latest events per individual. Study uploads may be active, delayed, embargoed or historical; repository packages archive completed research rather than guarantee live locations. | Fully public studies can use anonymous public JSON; other access requires permissions/account and potentially acceptance of study terms. API currently allows **one concurrent request/IP**, **20 total**; transfers remain active until complete. Use time windows/event budgets/reduced profiles. Repository offers downloadable DOI packages; size varies, so inspect before downloading. [API](https://github.com/movebank/movebank-api-doc/blob/master/movebank-api.md), [access](https://www.movebank.org/cms/movebank-content/access-data), [Repository](https://www.movebank.org/cms/movebank-content/data-repository). | A visible track on Movebank's map does **not** grant exact-coordinate download or external-map reuse permission. Owners control selected animals, recent-data embargoes and terms; CC0/BY/BY-NC are supported. Inspect each study/package licence and citation, preserve outlier/`visible` flags and never infer hidden fixes. [Permissions](https://www.movebank.org/cms/movebank-content/permissions-and-sharing), [data policy](https://www.movebank.mpg.de/cms/movebank-content/data-policy). |

## Narrow next integration gate

For the GBIF pilot, implement an opt-in native adapter with bounded historical queries, local cache, explicit empty/error/429 states and cancellation; no automatic global harvest. First qualify a tiny manually reviewed dataset/taxon selection using disposable state. Keep provider ID, dataset/occurrence IDs, canonical source URL, licence/attribution, original date precision, first-seen/update times, uncertainty/generalization and query bounds. Do not create station IDs for free-standing occurrence points or animal IDs from observer IDs.

Before shipping: verify that current event/position DTOs can distinguish occurrence points from receivers and individual fixes, retain coarse dates, and represent privacy/generalization without false precision. Establish correction/deletion refresh, cross-source duplicate handling (e.g. iNaturalist records republished through GBIF), source-health provenance, pagination/truncation totals and per-record export attribution. If the current contract cannot preserve these meanings, extend it before enabling the provider. Dataset choice, sensitivity review, exact export obligations, licence compatibility with the intended product use and live freshness remain unresolved gates. No specific study or dataset is approved by this memo.
