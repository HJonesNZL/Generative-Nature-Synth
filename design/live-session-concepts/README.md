# Animal Atlas live listening concepts

These three generated studies explore how to connect an audible species voice to its detection on the current Atlas screen. Species, locations, voice shapes and counters in the pictures are illustrative. Production location labels should identify the receiver for acoustic detections and retain the source’s uncertainty. The inherited overload counter in the renders is incidental.

| Concept | Interaction |
| --- | --- |
| [Map pulses](map-pulses.png) | Show a small outlined point on detection. Pulse at confirmed note onset and label the species, synth voice and place. Let the marker fade once the note finishes. |
| [Globe voices](globe-voices.png) | Give simultaneous notes matching numbers and shapes on the globe and voice strips. The strips identify each species, location and timbre while several voices overlap. |
| [Time ribbon](time-ribbon.png) | Keep a short playback trail under the map. Align the sounding note with Now so listeners can see the delay between arrival and playback. A short playback view could be a separate tab alongside the scrollable session ranking. |

Recommended first prototype: **Map pulses**. It works on both existing map projections. Add the voice strips from Globe voices when sounds overlap. As a starting point for listening tests, keep a soft trace for eight seconds after the note ends. Queued observations stay visually distinct even if they wait longer. Reduced-motion mode can use a fixed bright shape at onset. Fading should remove only the transient marker, never the session’s species count or stored record.
